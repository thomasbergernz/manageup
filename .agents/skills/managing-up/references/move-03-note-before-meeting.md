# Move 03 — The Note Before the Meeting

## Goal / Time

Shape one meeting before it happens. 15–20 minutes, sent 24 hours ahead.

Pick one meeting in the next 7 days that actually matters. Not a standup. Ever.

## Track switch

- **Boss track:** a meeting the user runs, or one they don't run but care about. Send the note to whoever runs it, and copy the user's boss or the right leader.
- **Client track:** the next client call, monthly review, or a pitch.

## Inputs to collect

Ask in one grouped message:

- **Scenario:** A (user runs the meeting), B (user doesn't run it but wants something covered), or C (client call the user is leading).
- **Meeting topic.**
- **Who's in the room:** names and titles.
- **What I need:** a decision on X / agreement on Y / a recommendation agreed on Z.
- **Anything sent ahead:** deck, memo, analysis, or "none".

## Prompt

Run verbatim, with scenario substituted:

> I'm sending a short note 24 hours before a meeting. Help me draft it.
>
> Scenario: [A: I run the meeting / B: I don't run it but want something covered / C: it's a client call I'm leading].
>
> Context:
> - Meeting topic: [what it's about]
> - Who's in the room: [names and titles]
> - What I need: [a decision on X / agreement on Y / a recommendation agreed on Z]
> - Anything sent ahead: [deck, memo, analysis, or "none"]
>
> Draft a 4–6 sentence note that: says the goal in one clear sentence, points to anything sent ahead and what to focus on, says where I think we should land if it's a recommendation, and closes with what I need from them in the meeting. Calm, direct, confident. Not soft, not chest-beating.

## Insight as guardrail

Four checks before returning:

1. Goal stated in one clear sentence at the top.
2. Points to anything sent ahead + what to focus on.
3. If the user asked for a recommendation landing spot, it's named.
4. Closes with what the user needs from them.

Tone: calm, direct, confident. Not soft, not chest-beating. If any sentence feels apologetic or performative, rewrite.

## Chains into

Move 04 (Recap) — same meeting, post-event. The note defines what the recap should confirm.
